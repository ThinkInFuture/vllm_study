注意力机制 (attention/)

5种NPU优化的注意力后端 · 上下文并行支持 · 15+文件

一、模块概述

attention目录包含针对不同模型特性优化的注意力后端，支持标准Transformer、MLA、SFA、DSA、FA3等多种架构。通过上下文并行（Context Parallel）支持超长序列推理。

def get_attn_backend_cls(use_mla, use_sparse, use_compress):
    # 根据模型配置选择注意力后端
    if use_mla:
        if use_sparse:
            return "vllm_ascend.attention.sfa_v1.AscendSFABackend"
        else:
            return "vllm_ascend.attention.mla_v1.AscendMLABackend"
    elif use_compress:
        return "vllm_ascend.attention.dsa_v1.AscendDSABackend"
    else:
        return "vllm_ascend.attention.attention_v1.AscendAttentionBackend"

四、后端详解

AscendAttentionBackend

标准注意力后端，适用于普通Transformer模型

  • Q/K/V矩阵乘法
  • 注意力掩码应用
  • Softmax归一化
  • 支持PagedAttention

AscendMLABackend

MLA多头潜在注意力，适用于DeepSeek系列

  • 低秩KV压缩（减少75%内存）
  • 共享KV头
  • Prefill/Decode分离元数据
  • 内存高效

AscendSFABackend

SFA稀疏注意力，适用于稀疏注意力模型

  • 稀疏注意力模式
  • 选择性计算
  • 计算优化
  • 支持KV卸载

AscendDSABackend

DSA动态稀疏注意力，适用于动态稀疏模型

  • 动态稀疏模式
  • 自适应计算
  • 索引器支持
  • KV计划管理

AscendFABackend

Flash Attention 3，高性能注意力实现

  • 分块计算
  • 内存优化
  • 高吞吐量
  • 适用于长序列

六、MLA注意力详解

MLA（Multi-head Latent Attention）是DeepSeek系列模型的核心创新，通过低秩KV压缩将注意力计算的内存占用减少75%。

图4：MLA注意力计算流程
sequenceDiagram
    participant U as 上游vLLM Worker
    participant M as AscendMLABackend
    participant O as ops/mla.py
    participant N as NPU
    
    U->>M: forward_batched(hidden_states, attn_metadata)
    M->>O: 调用mla_forward()
    O->>N: 低秩KV压缩
    O->>N: Q * K^T (压缩后)
    O->>N: Softmax
    O->>N: 注意力权重 * V
    N-->>O: 注意力输出
    O-->>M: 返回结果
    M-->>U: 输出hidden_states
vllm_ascend/attention/mla_v1.py（简化）
class AscendMLABackend(AttentionBackend):
    def forward_batched(self, hidden_states, attn_metadata):
        # 调用ops/mla.py中的MLA算子
        return mla_forward(
            hidden_states,
            attn_metadata.kv_cache,
            attn_metadata.mla_metadata
        )

七、上下文并行 (context_parallel/)

上下文并行将长序列分割到多个设备上计算，支持超长序列推理。DCP（Disaggregated Context Parallel）将Prefill和Decode分离到不同设备。

context_parallel/
├── __init__.py
├── attention_cp.py     # 上下文并行基类
├── common_cp.py        # DCPMetadataBuilderMixin, DCPImplMixin
├── mla_cp.py           # AscendMlaDCPImpl, AscendMlaDCPMetadataBuilder
├── sfa_cp.py           # AscendSFADCPImpl, AscendSFADCPMetadataBuilder
└── dsa_cp.py           # DSA上下文并行

上下文并行说明

1. DCP：分解计算，将Prefill和Decode分离到不同设备，提升资源利用率

2. PCP：流水线上下文并行，将序列分割到多个设备上流水线计算

3. 适用场景：超长序列（如100K+ token）的推理场景
