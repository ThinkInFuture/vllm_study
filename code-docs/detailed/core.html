核心模块 (core/)

项目核心功能实现，包括KV缓存管理、调度器等关键组件

核心模块架构

core模块是vLLM Ascend的核心，负责KV缓存管理、任务调度和性能优化。

graph LR A[core模块] --> B[KV缓存管理] A --> C[调度器] A --> D[性能优化] B --> B1[KV缓存接口] B --> B2[混合KV缓存管理器] B --> B3[块表管理] C --> C1[重计算调度器] C --> C2[短请求优先调度] C --> C3[动态负载均衡] D --> D1[内存优化] D --> D2[计算优化]

KV缓存的分配、使用和释放流程。

graph TD A[请求到达] --> B{是否有空闲块?} B -->|是| C[分配KV缓存块] B -->|否| D[等待或驱逐] D --> C C --> E[写入KV数据] E --> F[推理计算] F --> G{是否完成?} G -->|否| F G -->|是| H[释放KV缓存块] H --> I[返回结果]
