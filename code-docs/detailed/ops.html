自定义算子 (ops/)

NPU优化的自定义算子实现 · 90+文件 · 7大类别

一、模块概述

ops目录包含针对昇腾NPU优化的自定义算子，涵盖激活函数、归一化、线性层、位置编码、注意力算子、MoE融合算子等核心操作。共计90+个Python文件，包括大量Triton内核实现。

三、基础算子详解

文件关键类/函数功能说明
activation.pyAscendQuickGELU, AscendSiluAndMul, AscendSwigluOAIAndMul, AscendSwigluStepAndMulNPU优化的激活函数，融合计算减少内存访问。AscendSiluAndMul将SiLU和乘法融合为一个算子

rotary_embedding.pyAscendRotaryEmbedding, AscendYaRNRotaryEmbedding, AscendDeepseekScalingRotaryEmbedding, AscendMRotaryEmbeddingNPU优化的旋转位置编码，支持YaRN频率缩放、DeepSeek缩放、多维RoPE

class AscendRMSNorm(torch.nn.Module):
    def __init__(self, hidden_size, eps=1e-6):
        super().__init__()
        self.weight = torch.nn.Parameter(torch.ones(hidden_size))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 使用NPU专用内核计算RMSNorm
        return rms_norm_npu(x, self.weight, self.eps)

五、MoE融合算子 (fused_moe/)

MoE（Mixture of Experts）融合算子是大型模型推理的关键组件，负责专家路由、门控计算和负载均衡。

图3：MoE融合算子架构
graph LR
    A[fused_moe.py] --> B[gate_linear.py 门控计算]
    A --> C[router/ 路由器]
    A --> D[routed_experts.py 路由专家]
    A --> E[shared_experts.py 共享专家]
    A --> F[token_dispatcher.py Token分发]
    A --> G[eplb.py 负载均衡]
    
    C -->|选择专家| D
    F -->|分发Token| D
    D -->|计算结果| F
文件关键类/函数功能说明
fused_moe.pyfused_moe()融合MoE入口函数，协调路由、专家计算和Token分发
moe_mlp.pymoe_mlp()MoE MLP计算，执行前馈网络的专家计算
routed_experts.pyrouted_experts()路由专家计算，根据门控权重选择专家并执行计算
shared_experts.pyshared_experts()共享专家计算，所有Token都经过的共享前馈网络
token_dispatcher.pytoken_dispatcher()Token分发器，将Token分配给对应的专家
gate_linear.pygate_linear()门控线性层，计算每个Token对每个专家的权重
eplb.pyeplb()专家并行负载均衡，动态调整专家分布

六、Triton内核 (triton/)

Triton是内核编译器，用于编写高性能GPU/NPU内核。triton-ascend是Triton的昇腾版本，支持在NPU上编写高性能内核。ops/triton/目录包含30+个Triton内核文件。

sequenceDiagram
    participant Dev as 开发者

    participant Model as models/模型
    participant NPU as NPU设备
    
    Dev->>Ops: 定义算子类
    Ops->>Reg: 注册到vLLM torch library
    Model->>Reg: 查找已注册算子
    Reg-->>Model: 返回算子实现
    Model->>NPU: 调用算子执行
