一、模块概述

worker目录包含模型执行的核心组件，负责模型加载、推理执行和分布式协调。包含V1和V2两代ModelRunner实现，以及完整的子模块体系。

V1 vs V2区别

1. V1：继承自vLLM的GPUModelRunner，适配NPU实现

2. V2：全新架构设计，不继承GPU实现，直接针对NPU优化

3. V2优势：更好的扩展性，支持EPLB、PCP等高级特性

vllm_ascend/worker/model_runner_v1.py（简化）
class NPUModelRunner(GPUModelRunner):
    def __init__(self, vllm_config: VllmConfig):
        super().__init__(vllm_config)
        self.device = torch.device("npu")

    def execute_model(self, ...):
        # 1. 预处理输入
        input_ids = self._prepare_input_ids(...)
        
        # 2. 构建注意力元数据
        attn_metadata = self._build_attn_metadata(...)
        
        # 3. 模型前向传播
        hidden_states = self.model(input_ids)
        
        # 4. 调用attention和ops模块
        for layer in self.model.layers:
            hidden_states = layer.attention(hidden_states, attn_metadata)
            hidden_states = layer.feed_forward(hidden_states)
        
        # 5. 采样输出
        logits = self.model.head(hidden_states)
        return logits
