core\batch_job_aware_scheduler.py查看源码
面向离线/批量推理的批任务感知调度器（685 行）。核心思想：同一批任务（job）的请求被归入同一桶（RequestBucket，按 prefill 长度最佳适配 O(log n) 查找），调度时用 EWMA 估计每个 job 的 decode 长度（JobDecodeEstimator），并由 RunningBlockReserver 预测下一轮 running 循环的 KV 块需求，据此决定准入预算。主要类：JobNameParser（作业名解析缓存）、JobDecodeEstimator（decode 长度 EWMA 预测）、RunningBlockReserver（KV 块需求预留）、RequestBucket（按 prefill 长度分桶）、BatchJobAwareRequestQueue（作业分组排序 + 预留感知准入的请求队列）、BatchJobAwareScheduler/BatchJobAwareAsyncScheduler（调度器本体及异步变体）。_sort_jobs 按准入预算决定长任务/短任务谁优先。
类: BatchJobAwareRequestQueue, BatchJobAwareScheduler, BatchJobAwareAsyncScheduler
